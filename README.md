# 盘感练习

iPhone 上的离线 K 线盲测：日线 / 4 小时 / 1 小时，不含缠论、不含分钟线。  
这是独立发布仓库，和网页版 `market-replay` 分开。

线上地址（推送并打开 GitHub Pages 之后）：

**https://niclodian1.github.io/kpractice/**

---

## 第一次：装到 iPhone 主屏幕

1. 手机连 **Wi-Fi**（第一次要下载约 32MB K 线）。
2. 用 **Safari** 打开上面的地址（不要用微信 / 钉钉 / Chrome）。
3. 等首页出来后，点 **「下载全部品种」**，等到提示完成。
4. Safari 底部分享 → **添加到主屏幕** → 添加。
5. 以后从桌面图标进入。第一次缓存完成后，飞行模式也可以练。

系统建议 iOS 16.4 或更新。

## 日常怎么用

- **开始练习**：选品种 / 市场 / 级别 / 步数，点开始。盲测中不显示品种名和真实日期。
- **下一根**：底部按钮；也可外接键盘空格 / 右方向键。
- **开仓 / 加仓 / 平仓**：图表下方表单，逻辑必填。初始本金 100,000U。
- **揭示 / 放弃 / 再来一局**：走完步数会自动揭示。
- **导出 CSV**：回首页 → **导出全部练习明细 CSV** → 分享到「文件」或隔空投送。会导出所有练习局的逐笔（含放弃局）。

## 更新这个网站（你在电脑上）

K 线数据来自网页版仓库里的生成脚本。更新步骤：

```bash
# 在网页版仓库 fenxing 目录
python3 tools/publish_kpractice.sh

# 再提交发布仓库
cd ~/kpractice
git add -A
git status
git commit -m "更新练习数据"
git push
```

几分钟后打开 https://niclodian1.github.io/kpractice/ 即可。iPhone 上如还是旧版：Safari 打开该网址下拉刷新一次，或删掉主屏幕图标再添加。

## 说明

- 仓库是 **Public**，因为 GitHub 免费账号的 Pages 只对公开仓库开放。
- 数据只含 OHLCV，没有缠论结构。
- 练习记录存在手机本地（不会上传到 GitHub）。清 Safari 网站数据会丢掉战绩，导出 CSV 请先做。
